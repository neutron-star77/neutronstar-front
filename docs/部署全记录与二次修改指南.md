## 5. 已踩过的坑

- 旧站 / 旧 Worker 仍可能抢自定义域
- `editor.preview: false` 会让后台看起来像坏了
- `publish_mode: editorial_workflow` 会让单人博客误以为“保存没生效”
- `repoId` / `categoryId` 必须是 GitHub node_id，不是数字
- `.codex/` 可能残留运行日志并占用文件
- `pnpm build` 前没设 `CODEBUDDY_SAFE_DELETE_ENABLED='0'` 会踩清理守卫
- 本地预览不要用 4321

## 6. 二次修改建议

- 改主题与组件：先看 [前端微调指南](./前端微调指南.md)
- 改内容：优先改 `src/content/posts/` 或 `src/data/*.json`
- 改后台：优先改 `public/admin/config.yml`
- 改评论：优先改 `src/config/commentConfig.ts`
- 改搜索：优先改 `Search.svelte` 和 `Navbar.astro`

## 7. 部署复核顺序

1. `pnpm build`
2. 路由冒烟检查
3. `git status` 清干净
4. 推 `main`
5. 复核线上首页、文章页、后台、评论、搜索
