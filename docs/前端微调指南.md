# NeutronStar 前端微调指南

> 本文档说明 **NeutronStar 前端（Mizuki 复刻版）** 的每一处可自定义点：想改什么 → 改哪个文件 → 怎么改。
> 前端源码目录：`F:\AI\projects\blog\neutronstar-front`
> 线上站：https://blog.neutronstar.fun

---

## 0. 一句话总览

Mizuki 是「**配置驱动**」主题——90% 的个性化（站名、顶图、导航、头像、文案、主题色）都在 **`src/config/` 目录下的 6 个配置文件**里，改完跑 `pnpm build` 即可。剩下 10% 是内容（文章/友链/关于页）与数据（番剧/项目/技能等）。

**改完必做**：`pnpm build`（生成 `dist/`）→ 部署（见第 6 节）。

## 1. 改站点基本信息（站名/副标题/URL/时区/主题色）

**文件**：`src/config/siteConfig.ts`

| 想改什么 | 变量 | 例子 |
|---|---|---|
| 浏览器标题/SEO 站名 | `title` | `"NeutronStar"` |
| 站点副标题 | `subtitle` | `"星舰 AI 博客 · 深空中的思考"` |
| 站点 URL（必须斜杠结尾） | `siteURL` | `"https://blog.neutronstar.fun/"` |
| 站点起始日期（计算运行天数） | `siteStartDate` | `"2026-08-18"` |

| 主题色相（0-360） | `themeColor.hue` | `240`（蓝紫色） |
| 是否给访客换主题色 | `themeColor.fixed` | `true` = 锁定不让换 |

## 2. 改顶图轮播（你图床的图片）

**文件**：`src/config/siteConfig.ts` → `banner.src`

- `desktop`：桌面端横幅图 URL 数组
- `mobile`：移动端横幅图 URL 数组
- 数组长度 > 1 即**自动轮播**；只有 1 张则静态显示

当前已填入你的图床（GitHub `neutron-star77/fastimage` + jsDelivr CDN）14 张鬼刀壁纸：

```ts
desktop: [
  "https://cdn.jsdelivr.net/gh/neutron-star77/fastimage@main/2026/08/433.webp",
  // ... 更多
],
```

**想换图**：
1. 打开图床管理页 https://neutron-star77.github.io/fastimage/ 上传新图
2. 复制新图的 jsDelivr 链接
3. 替换 `desktop` / `mobile` 数组里的 URL（两处都要改，或 mobile 只留精选）

> 提示：banner 是整站氛围的关键，建议用 16:9 以上的宽幅图。

## 4. 改个人资料（头像/昵称/简介/社交链接）

**文件**：`src/config/profileConfig.ts`

| 想改什么 | 变量 |
|---|---|
| 头像 | `avatar`（`assets/images/avatar.webp` 本地文件，或图床 URL） |
| 昵称 | `name` |
| 个人简介 | `bio` |
| 简介打字机 | `typewriter.enable` / `speed` |
| 社交链接 | `links` 数组（`name`/`icon`/`url`） |

**换头像**：
- 本地方式：把图片放到 `src/assets/images/` 覆盖 `avatar.webp`
- 图床方式：直接把 `avatar` 改成 `https://cdn.jsdelivr.net/gh/.../xxx.webp`

**加社交链接**（以哔哩哔哩为例）：
```ts
{
  name: "Bilibili",
  icon: "fa7-brands:bilibili",   // 任意 Iconify 图标名
  url: "https://space.bilibili.com/你的uid",
},
```

## 5. 改导航菜单

**文件**：`src/config/navBarConfig.ts`

- `LinkPreset.Home` / `LinkPreset.Archive`：预设首页/归档
- 每个下拉菜单是 `{ name, url, icon, children: [...] }`
- `children` 里 `external: true` 表示新标签页打开外链

**当前菜单结构**（中文）：
```
首页 | 归档 | 链接▾ | 我的▾ | 关于▾ | 更多▾
        ├GitHub ├说说   ├关于我 ├项目
        └Email  ├相册   └友链   ├技能
                └设备           ├AI工具
                               └时间线
```

> 想改页面名/顺序/增删，直接改数组即可。`url` 必须对应该页面真实路径。

## 6. 改文章（写博客）

**位置**：`src/content/posts/*.md`（当前已有 10 篇，从旧后台导出）

每篇文章顶部是 frontmatter：

```md
---
title: "文章标题"
published: 2026-08-19        # 发布日期
draft: false                 # true = 草稿不显示
description: "摘要，显示在卡片上"
image: "https://...封面图"   # 封面图 URL（图床）
tags: ["标签1", "标签2"]
category: "分类"
---

正文用 Markdown 写，支持：
- 代码高亮（Expressive Code）
- KaTeX 数学公式 `$...$`
- 提示框 `> [!NOTE]` `> [!WARNING]`
- 图片网格、GitHub 卡片等扩展（见 src/content/spec/about.md 示例）
```

**新写一篇**：在 `src/content/posts/` 新建 `xxx.md`，用上面的模板。

## 12. 构建与部署

```powershell
# 构建（生成 dist/）
Set-Location F:/AI/projects/blog/neutronstar-front
$env:CODEBUDDY_SAFE_DELETE_ENABLED='0'   # 绕开 IDE 的 safe-delete 守卫
pnpm build

# 本地预览
pnpm preview

# 部署到 Cloudflare Pages（需要 wrangler 登录）
npx wrangler pages deploy dist --project-name=neutronstar
```

> 改完配置 → 重新 `pnpm build` → 部署，线上立即生效。

## 13. 常见问题（FAQ）

**Q: 改了配置没效果？**
构建缓存导致，先删除 `node_modules/.vite` 和 `dist/` 再 `pnpm build`。

**Q: 想彻底换个主题色？**
`siteConfig.ts` → `themeColor.hue` 改一个数字即可，全站颜色跟着变。

**Q: 顶图想加更多轮播图？**
在 `banner.src.desktop` / `mobile` 数组里加 URL 即可，数量不限。

**Q: 文章里的图片放哪？**
推荐放你自己的图床（https://neutron-star77.github.io/fastimage/），Markdown 里写 jsDelivr 链接。
