# NeutronStar 前端微调指南

> 本文档只负责 **NeutronStar 前端（Mizuki 复刻版）** 的“改什么 → 改哪个文件 → 怎么改”。

> 线上站：https://blog.neutronstar.fun

## 0. 一句话总览

Mizuki 是「**配置驱动**」主题。90% 的个性化（站名、顶图、导航、头像、文案、主题色）都在 **`src/config/` 目录下的 6 个配置文件**里；剩下的是内容（文章/友链/关于页）与数据（番剧/项目/技能等）。

改完后的构建、发布、清理规则见 [AGENTS.md](/F:/AI/projects/blog/neutronstar-front/AGENTS.md)，本指南不重复写命令层约束。

## 2. 改顶图轮播（你图床的图片）

**文件**：`src/config/siteConfig.ts` → `banner.src`

- `desktop`：桌面端横幅图 URL 数组
- `mobile`：移动端横幅图 URL 数组
- 数组长度 > 1 即**自动轮播**；只有 1 张则静态显示

当前已填入你的图床（GitHub `neutron-star77/fastimage` + jsDelivr CDN）14 张鬼刀壁纸：

```ts
desktop: [
  "https://cdn.jsdelivr.net/gh/neutron-star77/fastimage@main/2026/08/433.webp",
  // ... 更多
],
```

**想换图**：
1. 打开图床管理页 https://neutron-star77.github.io/fastimage/ 上传新图
2. 复制新图的 jsDelivr 链接
3. 替换 `desktop` / `mobile` 数组里的 URL（两处都要改，或 mobile 只留精选）

> 提示：banner 是整站氛围的关键，建议用 16:9 以上的宽幅图。

## 4. 改个人资料（头像/昵称/简介/社交链接）

| 想改什么 | 变量 |


## 5. 改导航菜单

**文件**：`src/config/navBarConfig.ts`

- `LinkPreset.Home` / `LinkPreset.Archive`：预设首页/归档
- 每个下拉菜单是 `{ name, url, icon, children: [...] }`
- `children` 里 `external: true` 表示新标签页打开外链

**当前菜单结构**（中文）：
```
首页 | 归档 | 链接▾ | 我的▾ | 关于▾ | 更多▾
        ├GitHub ├说说   ├关于我 ├项目
        └Email  ├相册   └友链   ├技能
                └设备           ├AI工具
                               └时间线
```

> 想改页面名/顺序/增删，直接改数组即可。`url` 必须对应该页面真实路径。

## 6. 改文章（写博客）

**位置**：`src/content/posts/*.md`（当前已有 10 篇，从旧后台导出）

每篇文章顶部是 frontmatter：

```md
---
title: "文章标题"
published: 2026-08-19        # 发布日期
draft: false                 # true = 草稿不显示
description: "摘要，显示在卡片上"
image: "https://...封面图"   # 封面图 URL（图床）
tags: ["标签1", "标签2"]
category: "分类"
---

正文用 Markdown 写，支持：
- 代码高亮（Expressive Code）
- KaTeX 数学公式 `$...$`
- 提示框 `> [!NOTE]` `> [!WARNING]`
- 图片网格、GitHub 卡片等扩展（见 src/content/spec/about.md 示例）
```

**新写一篇**：在 `src/content/posts/` 新建 `xxx.md`，用上面的模板。

## 10. 改评论系统（Giscus / Twikoo）

**文件**：`src/config/commentConfig.ts`

当前**已启用**，系统为 `giscus`。

### Giscus 当前配置

- `enable: true`
- `system: "giscus"`
- `giscus.repo: "neutron-star77/neutronstar-front"`
- `giscus.repoId: "R_kgDOT9lmVw"`
- `giscus.category: "Announcements"`
- `giscus.categoryId: "DIC_kwDOT9lmV84DDwtV"`
- `giscus.mapping: "pathname"`
- `giscus.theme: "preferred_color_scheme"`
- `giscus.lang: SITE_LANG`

### 什么时候改这里

- 想开 / 关评论：改 `enable`
- 想切评论方案：改 `system`
- 想修 Giscus 报错：先检查 repo 是否安装 Giscus App，再核对 `repoId` / `categoryId` 是否是 GitHub node_id
- 想换 Twikoo：改 `system: "twikoo"`，并补 `twikoo.envId`

### 常见坑

- `repoId` / `categoryId` 不能填数字，要填 node_id
- 仓库没装 Giscus App 会直接报“not installed on this repository”
- 如果评论组件不显示，先确认文章页 `comment` 不是 false

## 11. 改 Decap CMS 后台

**文件**：`public/admin/config.yml`

### 当前关键项

- `backend.name: github`
- `backend.repo: neutron-star77/neutronstar-front`
- `backend.branch: main`
- `backend.base_url: https://blog.neutronstar.fun`
- `backend.auth_endpoint: api/oauth/auth`
- `publish_mode: simple`
- `editor.preview: true`

### 它管什么

- 后台登录
- 保存后直接提交到 `main`
- Markdown 编辑器右侧实时预览
- `src/content/posts/`、`src/content/spec/`、`src/data/*.json` 的表单字段映射

### 改后台时的顺序

1. 先改 `public/admin/config.yml`
2. 再对照 `src/data/*.json` 或 Markdown frontmatter
3. 用浏览器打开 `/admin/` 实测登录和保存
4. 保存成功后看 GitHub / Pages 是否自动重建

### 常见坑

- `editor.preview: false` 会关掉实时预览
- `publish_mode: editorial_workflow` 会让单人博客看起来像“保存了但没发版”
- `backend.base_url` 必须是纯 origin，不要带路径
- 如果 `/api/oauth/auth` 500，先查 CF Pages Secrets 有没有 `OAUTH_CLIENT_ID` 和 `OAUTH_CLIENT_SECRET`

## 12. 改搜索（Pagefind）

**相关文件**：

- `package.json`
- `src/components/organisms/navigation/Search.svelte`
- `src/components/organisms/navigation/Navbar.astro`

### 当前状态

- 构建链已经启用 Pagefind：`pnpm build` 里包含 `pagefind --site dist`
- 线上资源路径固定在 `/pagefind/`
- 首页和文章页都能通过导航里的搜索按钮打开搜索面板

### 怎么改

- 想改搜索入口样式：看 `Search.svelte`
- 想改导航里搜索按钮位置：看 `Navbar.astro`
- 想改 Pagefind 的索引行为：先改构建链或页面收录范围，再 build 验证

### 中文搜索说明

- 站点语言是 `zh_CN`
- Pagefind 对中文不会像英文那样做词干化
- 实测中文词可以正常命中，例如 `革命`、`技术`、`深空`

### 常见坑

- 生产环境下才会真正加载 `window.pagefind`
- 开发环境里搜索面板会走 mock/fake 数据
- 如果搜索面板没结果，先确认 `/pagefind/pagefind.js` 是否 200，再确认构建时是否真的跑了 Pagefind

## 14. 常见问题（FAQ）

**Q: 改了配置没效果？**
构建缓存导致，先删除 `node_modules/.vite` 和 `dist/` 再 `pnpm build`。

**Q: 想彻底换个主题色？**
`siteConfig.ts` → `themeColor.hue` 改一个数字即可，全站颜色跟着变。

**Q: 顶图想加更多轮播图？**
在 `banner.src.desktop` / `mobile` 数组里加 URL 即可，数量不限。

**Q: 文章里的图片放哪？**
推荐放你自己的图床（https://neutron-star77.github.io/fastimage/），Markdown 里写 jsDelivr 链接。

**Q: 部署/二次修改/踩坑去哪里看？**
看 [docs/部署全记录与二次修改指南.md](/F:/AI/projects/blog/neutronstar-front/docs/部署全记录与二次修改指南.md)。
